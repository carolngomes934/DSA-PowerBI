# 👥 Mini Projeto 3 – Análise de Dados de RH

## Objetivo
Criar um painel de indicadores de Recursos Humanos para monitorar o perfil do quadro de funcionários, disponibilidade para hora extra e nível de engajamento no trabalho, apoiando decisões de gestão de pessoas.

## Principais análises realizadas
- Indicadores gerais: **1.400 funcionários**, salário médio de R$ 6.927,51 e experiência média de 11 anos
- Distribuição por gênero: 59,86% masculino e 40,14% feminino
- Disponibilidade para hora extra: apenas 28,43% dos funcionários estão disponíveis
- Distribuição por função/cargo: Cientista de Dados, Analista de Dados, Engenheiro de IA, Arquiteto de Dados, Engenheiro de Dados e Engenheiro Analítico
- Faixa etária da equipe (18 a 60 anos)
- Nível de envolvimento no trabalho, classificado em Alto, Médio, Baixo e Ruim

## Principais insights
- A maioria dos funcionários (59%) apresenta envolvimento **Médio** no trabalho, e apenas ~10% têm envolvimento Alto
- Menos de 1/3 do time está disponível para hora extra, o que pode ser um ponto de atenção para picos de demanda
- O quadro é majoritariamente masculino, mas com uma diferença moderada em relação ao feminino (~20 p.p.)

## Técnicas e recursos utilizados
- Cartões de indicadores (KPIs) para métricas-chave
- Gráficos de rosca/pizza para proporções (gênero, hora extra, envolvimento)
- Gráfico de barras para distribuição por função
- Modelagem de dados de RH (idade, cargo, engajamento, disponibilidade)
